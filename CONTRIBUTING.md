# Contributing to txttovoice

Thank you for your interest in contributing to txttovoice! 🎤

## 🚀 Quick Start

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/txt-to-voice.git`
3. Create a feature branch: `git checkout -b feature/amazing-feature`
4. Make your changes
5. Test thoroughly
6. Commit: `git commit -m 'Add amazing feature'`
7. Push: `git push origin feature/amazing-feature`
8. Open a Pull Request

## 🛠️ Development Setup

```bash
# Clone the repository
git clone https://github.com/MafConQuest/txt-to-voice.git
cd txt-to-voice

# Install dependencies
pip install -r requirements.txt

# Run the application
python txttovoice.py
```

## 🧪 Testing

Before submitting a PR, please test:

1. **Installation**: Run `install.bat` on a clean Windows machine
2. **Core Features**: 
   - Manual text input and speech
   - Global hotkey (Ctrl+Shift+J) with selected text
   - System tray functionality
   - Settings dialog
3. **Edge Cases**:
   - Long text (>1000 characters)
   - Special characters and emojis
   - Different applications (browser, notepad, Word, etc.)

## 📝 Code Style

- Follow PEP 8 for Python code
- Use meaningful variable and function names
- Add docstrings for new functions
- Keep functions focused and small
- Comment complex logic

## 🐛 Bug Reports

When reporting bugs, please include:

- **OS Version**: Windows 10/11 version
- **Python Version**: `python --version`
- **txttovoice Version**: Check About dialog
- **Steps to Reproduce**: Detailed steps
- **Expected vs Actual**: What should happen vs what happens
- **Logs**: Check `%USERPROFILE%\.txttovoice\app.log`

## 💡 Feature Requests

We welcome feature requests! Please:

1. Check existing issues first
2. Describe the use case
3. Explain why it would be valuable
4. Consider implementation complexity

## 🎯 Priority Areas

We're especially interested in contributions for:

- **Performance improvements**
- **Additional TTS providers** (Azure, Google, Amazon)
- **Accessibility features**
- **Internationalization**
- **Better error handling**
- **Unit tests**

## 📋 Pull Request Guidelines

- **One feature per PR**
- **Clear description** of changes
- **Test your changes** thoroughly
- **Update documentation** if needed
- **Keep commits atomic** and well-described

## 🔒 Security

If you discover a security vulnerability, please email security@txttovoice.com instead of opening a public issue.
